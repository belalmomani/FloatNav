# شريط التنقل العائم (FloatNav)

تطبيق أندرويد أصلي (Kotlin، بدون أي مكتبات خارجية، بدون WebView).

## البناء عبر GitHub
1. أنشئ مستودعًا جديدًا وارفع محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
2. عند كل push إلى `main` يعمل Workflow باسم **Build APK** تلقائيًا (أو شغّله يدويًا من تبويب Actions).
3. بعد انتهائه: Actions ← آخر تشغيل ← **Artifacts** ← `FloatNav-debug-apk` ← نزّل الملف وفك الضغط ثم ثبّت `app-debug.apk`.

## الاستخدام
1. افتح التطبيق ← «فتح إعدادات خدمة الوصول» ← فعّل «شريط التنقل العائم».
2. (اختياري) امنح «إحصاءات الاستخدام» لتفعيل الزر الذكي التلقائي.
